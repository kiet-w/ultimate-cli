2. ⚡ Phím Tắt Thoát CLI & Bỏ Qua Đặt Tên

Quick Exit
  • ➜
    Bỏ qua không cần đặt tên khi gặp Prompt:
    Nhấn Enter trực tiếp (để trống) để tự động sinh tên theo thời gian, hoặc nhấn Esc / Ctrl+C lần 2 để thoát ngay.
  • ➜
    Thoát nhanh chuẩn terminal không bị hỏi:
    Nhấn Ctrl + D hai lần liên tiếp (Ctrl+D Ctrl+D).
  • ➜
    Thoát bằng lệnh trong chat:
    Gõ /exit hoặc /quit để thoát an toàn và tự động in mã resume.

3. 🏷️ Quản Lý, Đổi Tên & Gán Category Sau

Session Management

Bạn không cần đặt tên ngay lúc thoát, có thể đổi tên và gán lại category bất cứ khi nào:

/resume
  1. Gõ lệnh /resume (hoặc /switch) để mở Session Picker.
  2. Dùng phím mũi tên ↑ / ↓ chọn phiên chat mong muốn.
  3. Nhấn phím F2, nhập Tên mới hoặc chỉnh Category rồi bấm Enter.

4. 🗄️ Cấu Trúc File Log & Lệnh Tra Cứu

Log System

Đường dẫn lưu log chuẩn trên máy:

~/.gemini/antigravity-cli/brain/<conversation-id>/.system_generated/logs/transcript.jsonl

Các câu lệnh Terminal tra cứu nhanh:

# 1. Tìm lại câu hỏi / nội dung trong toàn bộ log: grep -r "từ_khóa" ~/.gemini/antigravity-cli/brain/*/.system_generated/logs/transcript.jsonl
# 2. Xem tất cả prompt của người dùng trong một phiên: grep '"type":"USER_INPUT"' ~/.gemini/antigravity-cli/brain/<ID>/.system_generated/logs/transcript.jsonl

5. 🌐 Cách Đưa File Này Lên Web (Hosting Miễn Phí)

Web Deployment

File này hoàn toàn độc lập (Zero-dependency). Bạn có các cách chạy và chia sẻ như sau:

  • 1.
    Mở trực tiếp trên máy bằng trình duyệt:
    xdg-open ~/agy_guide.html
  • 2.
    Chạy Local Web Server nhanh với Python:
    python3 -m http.server 8080 # Sau đó mở http://localhost:8080/agy_guide.html
  • 3.
    Đẩy lên GitHub Pages / Vercel (Online 24/7):
    Chỉ cần đổi tên file thành index.html, đưa vào GitHub Repository và bật GitHub Pages trong phần Settings là bạn đã có một link web online (ví dụ https://your-name.github.io/agy-guide) hoàn toàn miễn phí.
